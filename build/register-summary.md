# I-GUIDE Building Blocks

OGC Building Blocks describing datasets published on the [I-GUIDE Platform](https://platform.i-guide.io/).


Schemas, JSON-LD semantic annotations and SHACL rules for datasets hosted on the I-GUIDE Platform,
so that their records can be validated and published as linked data.


## Building Blocks

### `iguide.bbr.chicagoCrime` — Chicago Crime Record

**Type:** schema

Schema and semantic annotation for a single reported crime incident from the City of Chicago 'Crimes - 2001 to Present' dataset, as published on the I-GUIDE Platform (Chicago Crime data 2026).

### `iguide.bbr.mySchema` — My Schema

**Type:** schema

An example schema defining the set of properties of any type of object.

### `iguide.bbr.myFeature` — Custom Feature

**Type:** schema

This examples shows a simple customisation for OGC API Feature schemas
